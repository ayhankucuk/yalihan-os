# YALIHAN OS Project Brain

Bu klasör projenin kanıt-odaklı kurumsal hafızasıdır.

## Kullanım sırası

1. `PROJECT_STATE.md` — güncel genel durum
2. `ARCHITECTURE_MAP.md` — sistem ve veri akışları
3. `FEATURE_MATRIX.md` — özelliklerin gerçek durumu
4. `EVIDENCE_INDEX.md` — kanıt kaynakları ve güven seviyesi
5. `KNOWN_ISSUES.md` — açık sorunlar
6. `DECISION_LOG.md` — mimari ve operasyon kararları
7. `UPDATE_PROTOCOL.md` — güncelleme standardı
8. `PRODUCTION_LEDGER.md` — deploy ve canlı doğrulama kayıtları
9. `DOMAIN_GLOSSARY.md` — ortak kavram sözlüğü
10. `QUALITY_GATES.md` — tamamlanma ve yayın kalite kapıları
11. `RELEASE_CHECKLIST.md` — release yönetimi
12. `SECURITY_PROTOCOL.md` — sır ve güvenlik kuralları
13. `INCIDENT_LOG.md` — hatalardan öğrenme kaydı
14. `ADR_INDEX.md` — mimari karar kataloğu
15. `IMPACT_ANALYSIS.md` — değişiklik etki analizi
16. `EVIDENCE_RECORD_TEMPLATE.md` — kanıt kaydı şablonu
17. `DATA_CONTRACT_CHECK.md` — veri sözleşmesi denetimi
18. `OBSERVABILITY_PLAN.md` — gözlemlenebilirlik planı
19. `ROLLBACK_SIMULATOR.md` — geri alma analizi

Bu yapı sohbet hafızasının yerine geçmez; kod, Git, test ve üretim kanıtlarını birbirine bağlayan repository içi SSOT katmanıdır.
