## Capability Değerlendirme Standardı

Her capability için inceleme sırası:

### 1. 🎯 Business Hypothesis
- Hangi manuel operasyon otomatikleşiyor?
- Hipotez açık ve ölçülebilir mi?

### 2. 📈 BAI Impact
- Beklenen BAI etkisi nedir?
- Ölçüm yöntemi tanımlanmış mı?

### 3. 🏛 Architecture
- SAAB ilkeleri korunuyor mu?
- Capability sınırları ihlal edilmiyor mu?
- Başka capability'nin sorumluluğu üstleniliyor mu?

### 4. ⚙️ Implementation
- Thin controller
- Service layer
- Replay-safe
- Tenant-safe
- Idempotent
- Test edilebilir tasarım

### 5. 🧪 Evidence
- Test kapsamı yeterli mi?
- Regression temiz mi?
- Executive Report beklenen etkiyi doğruluyor mu?

### 6. 📚 Learning
- Beklenen–gerçekleşen farkı (Variance)
- Öğrenilen ders
- Sonraki capability için çıkarımlar
