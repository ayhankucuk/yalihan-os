## Key Design Decisions

### 1. Adapter Sadece Transform Yapar
```
Adapter ≠ iş mantığı
Adapter ≠ API çağrısı
Adapter ≠ validation (sadece dönüştürme)
```

### 2. No Real API Calls
Adapter'lar sadece `ChannelPayloadDTO` üretir.
HTTP client yok. Gelecek sprint'lerde `ChannelApiClient` ayrı katman olacak.

### 3. TenantScope Korunur
`withoutGlobalScopes()` kullanılmaz.
Tüm query'ler `TenantScope` içinde çalışır.

### 4. Immutable Events
`PublishingPackageReady` event'i `Imutable` trait'i kullanır.

### 5. Idempotent Job
`PreparePublishingJob` unique ID ile idempotent çalışır.
