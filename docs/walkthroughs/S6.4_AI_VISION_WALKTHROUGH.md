## Core Components

### 1. Vision Provider Architecture
**Location:** `app/Services/Vision/`

```
Contracts/
  VisionProviderContract.php  ← Interface

Providers/
  OpenAIVisionProvider.php   ← Real GPT-4o Vision
  MockVisionProvider.php      ← Test/development
```

Provider abstraction ensures business logic is never coupled directly to GPT-4 Vision.

### 2. Confidence Fusion Strategy
**Location:** `app/Services/Vision/VisionFusionEngine.php`

```
Rule Engine (RoomDetectionService)
        +
AI Vision Provider
        ↓
Confidence Weighted Average
        ↓
Final Classification

Rules:
  1. AI confidence > 0.85 → trust AI
  2. Rule confidence > 85 → trust rule
  3. Both moderate (0.5–0.85) → weighted average
  4. One very weak (<0.3) → trust the stronger one
  5. Both weak → "other" with low confidence
```

### 3. AI Room Detection
Extends `RoomDetectionService` (Sprint 6.3).
Supported room types: Living Room, Kitchen, Bedroom, Bathroom, Dining Room, Pool, Garden, Terrace, Exterior, View, Other.

### 4. AI Image Quality
Extends `ImageQualityEngine` with AI dimensions:
- Composition
- Luxury Appeal
- Marketability
- Professional Quality

### 5. AI Metadata Extraction
Extracts: Room descriptions, Furniture, Amenities, Luxury features, View type, Architectural style.

### 6. Publishing Preparation
Generates output (NOT publishing):
- Hero photo suggestion + reason
- Photo ordering
- Photo captions (title hints)
- Room metadata per photo
- Publishing readiness assessment

## Queue

**Job:** `AnalyzeVisionJob`
- async ✓
- idempotent (uniqueId per ilan) ✓
- retry safe (3 tries, 60s backoff) ✓
- timeout (180s) ✓
- replay safe ✓

## Database Columns

### `ilan_fotograflari`
- `vision_data` (JSON) — AI analysis metadata

### `ilanlar`
- `vision_score` (tinyint) — 0–100 aggregate
- `vision_ai_confidence` (decimal) — average AI confidence
- `vision_rooms` (JSON) — room distribution
- `vision_amenities` (JSON) — detected amenities
- `vision_luxury` (JSON) — luxury features
- `vision_media` (JSON) — full publishing media DTO

## Workflow

```php
// Trigger vision analysis
AnalyzeVisionJob::dispatch($ilanId);

// Or synchronous via orchestrator
$orchestrator = app(VisionOrchestrator::class);
$result = $orchestrator->analyzeIlan($ilanId);

// Result shape:
[
    'ilan_id'   => $ilanId,
    'analyzed'  => $count,
    'analyses'  => VisionAnalysisDTO[],
    'aggregated' => [...],
    'publishing' => PublishingMediaDTO,
]
```
