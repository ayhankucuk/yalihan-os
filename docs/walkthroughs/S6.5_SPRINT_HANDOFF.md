## Sprint 6.6 İçin Bırakılan Notlar

### 1. Adapter'lar Değiştirilmemeli
`AirbnbAdapter`, `SahibindenAdapter`, `HepsiemlakAdapter` sadece transform yapar.
Yeni kanal eklemek = yeni adapter yazmak. Mevcut adapter'lara dokunma.

### 2. ChannelApiClient Ayrı Katman Olmalı
```
Adapter.buildPayload() → ChannelPayloadDTO
        ↓
ChannelApiClient.send(ChannelPayloadDTO) → HTTP POST/PUT
```
Adapter'lar API çağrısı yapMASIN. ApiClient ayrı service olarak yazılmalı.

### 3. Publish Sonrası State Geçişi
`PublishingPackageReady` event'i yakalanarak workspace state'i güncellenmeli:
```
workspace.state: draft → publish_ready → published
```

### 4. Retry/Rate-Limit Ayrı Katman
`CircuitBreaker` + `RateLimiter` ayrı service'ler olmalı.
`ChannelApiClient` bunları inject etmeli.

### 5. Readiness UI Dashboard
`ChannelReadinessDTO` → Blade view'e dönüştürülecek.
Her kanal için ayrı kart: durum, readiness_score, missing_fields.
