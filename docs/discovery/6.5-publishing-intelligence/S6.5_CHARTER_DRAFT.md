# Scope
## P0
### 1. Channel Adapter Architecture
Provider Abstraction
  ChannelAdapterContract
    Implementations
    - AirbnbAdapter
    - SahibindenAdapter
    - HepsiemlakAdapter
  Never couple business logic directly to a portal API.
  Factory/Registry ile provider seçimi.
  Sabit kural: Adapter sadece dönüştürür — API çağrısı sonraki sprint'te.

### 2. DTO Layer
Yazılacak DTO'lar:
  ChannelPayload — kanal-agnostik payload container
  AirbnbFormatDTO — Airbnb-spesifik field mapping
  SahibindenFormatDTO — Sahibinden-spesifik field mapping
  HepsiemlakFormatDTO — Hepsiemlak-spesifik field mapping
  PublishingDecisionDTO — typed PublishDecisionAgent çıktısı

### 3. AI Content Transformation
TitleTransformer
  AI Vision title_hints → kanal formatına
DescriptionTransformer
  AI açıklama parçacıkları → kanal formatına
  NOT AI description generation — bu ayrı sprint
AmenityMapper
  vision_amenities → kanal-özgü özellik eşleşmeleri
RoomTypeMapper
  detected_rooms → kanal kategori/konum eşleşmeleri

### 4. Publish Readiness Gate
Tüm kanallar için ortak minimum eşik kontrolü.
Eksik alan varsa hangi kanalların "hazır" olduğunu döner.
ChannelReadinessAssessment DTO.

### 5. Publishing Intelligence Orchestrator
Tüm bileşenleri koordine eder.
Input: Ilan + Vision verileri + karar
Output: PublishingPackage
Pipeline:
  1. Ilan verisi oku (TenantScope korunur)
  2. PublishDecisionAgent kararını oku
  3. AI Vision verilerini oku (vision_media JSON)
  4. Her kanal için Adapter.buildPayload() çağır
  5. ChannelReadinessAssessment üret
  6. Workspace lifecycle etkilemez (sonraki sprint)
  7. Events fırlat
  8. Dön (Publish etmez)

### 6. Queue + Job
PublishPrepareJob
  async
  idempotent (uniqueId per ilan)
  retry-safe
  Tenant korunur
  Timeout: 60s
  replay-safe

### 7. Events
PublishingPackageReady
  Immutable
  Payload: ilan_id, channels, readiness, vision_confidence

### 8. Workspace Cockpit Extension
Yeni "Publishing Intelligence" paneli.
Kanal bazlı readiness durumu.
Kanal adapter'ların runtime kolonluk durumu.
Mevcut cockpit'e entegre — yeni sayfa yok.
