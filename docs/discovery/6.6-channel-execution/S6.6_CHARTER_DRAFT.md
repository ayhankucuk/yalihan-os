# Scope
## P0

### 1. ChannelExecutionLog Model
Tablo: channel_execution_logs
Enum: pending/approved/exported/failed/skipped
Tenant korunur — her execution tenant-logged
payload_hash ile idempotent tekrar koruması
retry_count ile replay güvenliği

### 2. Execution Plan (Batch)
UUID execution_id ile birden fazla kanal tek seferde planlanır.
Payload üretilmeden önce log kaydı açılır.
ChannelAdapterContract üzerinden adapter çağrılır.

### 3. Manual Export
Kanal payload'ı panoya/dosyaya kopyalanabilir formatta.
Adapter değil — Agent/Service katmanı taşır.
Export payloadhazırlanır — real API çağrısı YOK.

### 4. Replay Koruması
payload_hash ile aynı içerik tekrar üretilirse SKIPPED.
Sadece FAILED veya PENDING kanallar replay'e girer.
EXPORTED kanallar dokunulmaz.

### 5. Channel Status Dashboard Entegrasyonu
Workspace cockpit'e Publishing Intelligence paneli eklenmez (yeni sayfa YOK).
Mevcut cockpit genişletilir.
Lifecycle state harici kanal durumları TenantLog içinde izlenir.

### 6. Audit Trail
Kim? Ne zaman? Hangi payload? Sonuç ne?
Export her zaman immutable log'lanır.
Tenant isolation korunur.

## P1
Hermes publish komutu tetikler.
Workspace state geçişleri log'lanır.
Agent tabanlı execution pipeline pipeline.
Job idempotency güvenliği.

## Out Of Scope

Kanal-ö dışı iş mantığı.

# Architecture

## Directory

```
app/
  Models/
    ChannelExecutionLog.php
  Contracts/Publishing/
    ExecutionHandlerContract.php
  Services/Publishing/
    ChannelExecutionService.php       ← Ana koordinatör
    Exporters/
      AirbnbExporter.php            ← Panel/PDF/JSON export
      SahibindenExporter.php
      HepsiemlakExporter.php
    ExecutionLogger.php             ← Audit trail
  Http/Controllers/Api/
    ChannelExecutionController.php
  Jobs/
    ExecuteChannelExportJob.php     ← Async export job
  Events/
    ChannelExecutionCompleted.php

resources/views/admin/cockpit/  ← Mevcut cockpit genişletilir

tests/
  Unit/Services/Publishing/Execution/
  Feature/Publishing/Execution/
```

## Execution Flow

```
PreparePublishingJob
        ↓
PublishingIntelligenceOrchestrator
        ↓
PublishingPackageReady event
        ↓
[CHANNEL_EXECUTION_TRIGGER — Dashboard butonu]
        ↓
ChannelExecutionService::dispatch()
        ↓
ExecuteChannelExportJob (per channel)
        ↓
AirbnbExporter / SahibindenExporter / HepsiemlakExporter
        ↓
ChannelExecutionLog::exported
        ↓
Cockpit güncellenir
```
