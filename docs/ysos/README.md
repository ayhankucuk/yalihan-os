# YSOS — Yalıhan Sprint Operating System

> **Version:** 1.0

> **Status:** ACTIVE

---

## What is YSOS?

YSOS is the **engineering operating system** for YALIHAN OS.

It is not documentation. It is not a sprint template.
It is the system that governs how AI agents develop software on this repository.

---

## Core Principle

```
Repository = Memory
Sprint     = Execution Unit
Workspace  = Business Unit
Hermes     = Orchestrator
SAAB       = Governor
Git        = History
AI         = Workforce
Context    = Shared Intelligence
```

---

## YSOS Hierarchy

```
YSOS (Engineering OS)
├── YSOS Framework      — How sprints work
├── SAAB v7             — Governance rules
├── Sprint Lifecycle    — Every sprint follows the same stages
├── Quality Gates        — Automated verification
├── AI Agent Rules      — How agents behave
├── Context Engineering — How context is loaded
├── Evidence Standard    — How work is documented
├── Certification        — When a sprint is done
└── Handoff Standard    — How knowledge transfers
```

---

## Quick Start

Every new sprint begins with:

```bash
# 1. Read YSOS
# 2. Read current Sprint Charter
# 3. Read previous Handoff
# 4. Initialize new Sprint Workspace
# 5. Validate
# 6. Get SAAB approval
# 7. Implement
# 8. Certify
# 9. Handoff
# 10. Close
```
